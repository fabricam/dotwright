# Squad Decisions

## Active Decisions

### Dotwright.Playwright Library Design (Fenster, 2026-06-15)
- **Target framework:** net10.0 (parity with Blazor WASM host)
- **Namespace structure:** Dotwright.Playwright for library; models under Dotwright.Playwright.Models
- **Service lifetime:** IPlaywrightReportReader as Singleton (stateless, thread-safe, uses System.IO)
- **Registration:** AddPlaywrightReporting() extension in PlaywrightReportingServiceCollectionExtensions
- **Constraint:** Reader must be registered server-side only (uses File I/O; won't work in WASM)
- **Status:** Implemented in branch squad/add-playwright-library; dotnet build verified

### NuGet Package Configuration (Boltz, 2026-06-15)
- **Package ID:** Fabricam.Dotwright.Playwright
- **Version:** 0.1.0
- **Target framework:** net10.0
- **Publishing:** GitHub Packages auto-publishes on main branch merge
- **Authentication:** Uses built-in GITHUB_TOKEN; no additional secrets needed
